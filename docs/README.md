# docs

本目录记录 `arturo-test` 的项目演进、当日验证报告、对话决策总结和后续计划。

## 为什么需要 docs/date 文件夹

这个仓库的价值不只是保存 `.art` 测试文件，还要保存：

- 当天为什么这样组织项目。
- 哪些官方示例已经验证过。
- 哪些示例暂时不能原样自动跑。
- 哪些现象需要反馈给上游 `arturo-language-skill`。
- agent 写 Arturo 代码时新增了哪些经验。

因此按日期建立目录：

```text
docs/YYYY-MM-DD/
  README.md
  项目变更.md
  测试报告.md
  对话总结.md
```
