# 2026-08-19 项目变更

## 1. 仓库定位明确

`arturo-test` 的定位被明确为：

> 辅助 `arturo-language` skill 创建和迭代的验证仓库，为 agent 编写 Arturo 代码积累大量可验证、可反馈、可复用的示例。

本仓库不追求替代上游 skill，而是为上游 skill 提供：

- 官方示例验证结果。
- 模块化测试用例。
- 实战项目样例。
- 反馈与经验文档。

## 2. 不 vendor 上游 skill

用户指出上游 skill 会经常更新，因此本仓库不应提交 `scifx/arturo-language-skill` 的内容。

最终约定：

- 不提交 `skills/arturo-language/`。
- `.gitignore` 忽略 `skills/`。
- 测试脚本不自动 clone/fetch skill。
- 使用者自己按需准备或更新 skill：

```bash
git clone https://github.com/scifx/arturo-language-skill.git /tmp/arturo-language-skill
# 需要更新时手动执行：
git -C /tmp/arturo-language-skill pull --ff-only
```

## 3. 测试 runner 只使用已有 runtime

`tests/run-all.sh` 的职责被收窄为：

- 查找已有 Arturo runtime。
- 运行本仓库中的 `.art` 测试。
- 不联网。
- 不自动拉取上游 skill。

runtime 查找顺序：

1. `ARTURO_BIN`
2. `ARTURO_SKILL_DIR/bin/arturo`
3. `skills/arturo-language/bin/arturo`
4. `/tmp/arturo-language-skill/bin/arturo`

## 4. 官方模块目录补齐

`tests/modules/` 参照 Arturo 官方 library module 分区，补齐 26 个目录：

```text
arithmetic  bitwise      collections  colors      comparison
core        crypto       databases    dates       exceptions
files       io           iterators    logic       net
numbers     paths        quantities   reflection  sets
sockets     statistics   strings      system      types
ui
```

每个目录都要求有：

```text
README.md
反馈.md
经验.md
官方示例.md
```

如果该模块有可安全整模块原样执行的官方示例，还会有：

```text
official-examples-smoke.art
```

## 5. 官方示例同步工具

新增：

```text
tools/sync-library-examples.py
```

功能：

- 读取已经准备好的上游 skill runtime 和 `references/library-index.csv`。
- 对每个 symbol 执行等价查询：

```arturo
info.get 'symbol | get 'example
```

- 将结果写入：

```text
tests/modules/<module>/官方示例.md
examples/library/<module>.md
```

- 对已实测可原样整模块运行的模块，生成：

```text
tests/modules/<module>/official-examples-smoke.art
```

重要：该工具不 clone、不 fetch、不自动联网。
