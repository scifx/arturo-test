## 暂不原样自动执行的模块

这些模块的官方示例已导入 `官方示例.md`，但不直接生成 raw smoke，因为原样执行不稳定或有外部条件：

| 模块 | 原因 |
|---|---|
| `collections` | 原始示例中存在当前 runtime 不兼容/疑似陈旧写法，例如 `contains? dict "John"` 报错。 |
| `core` | 包含 `call.external` / 外部动态库示例，缺少 `libmylib.so`。 |
| `databases` | 示例依赖数据库状态，原样跑会出现表不存在等问题。 |
| `exceptions` | 包含当前 runtime 未解析的错误类型名/示例差异。 |
| `files` | 包含远程 URL 读取等网络相关示例。 |
| `io` | 包含 `input`，非交互测试会 EOF。 |
| `iterators` | 原样整模块执行会超时/长时间输出，需要拆分或跳过无限/惰性示例。 |
| `logic` | 有原始示例片段解析失败，需要逐条改写。 |
| `net` | 网络相关，环境依赖强。 |
| `numbers` | 存在当前 runtime 未解析函数，例如 `angle`。 |
| `reflection` | 可执行但输出极大，暂不放入默认回归，避免噪音。 |
| `sockets` | 启动 socket server，原样执行会等待/超时。 |
| `strings` | 整模块 raw 示例仍有陈旧片段；`upper?` 在 curated 总章测试里已通过。 |
| `system` | 包含环境/编码/进程相关差异，原样执行不稳定。 |
| `types` | 有示例片段解析失败，需要逐条清理。 |
| `ui` | UI 功能在当前无 UI/可能 MINI 环境不可用。 |

### 新发现的 runtime 差异

1. **`suffix?` 不支持 regex** — `suffix? "hello" {/\w/}` 返回 `false`，但 `prefix?` 正常。
2. **`` `x` `` 是 `:unit`** — `pad.with:`0` 报 TypeError；须 `pad.with: (first "0")`。
3. **`escape.shell` 不加多余引号** — 纯字母串原样返回。
4. **`truncate` 省略号前有空格** — `truncate "Hello World" 5` → `"Hello ..."`（空格+三点），`.preserve` 模式才无空格。

## 结论

当前项目组织已经证明可以：

1. 从官方 `info.get` 示例开始批量沉淀默认示例。
2. 区分“可原样执行的官方示例”和“需要 curated 改写的官方示例”。
3. 用 `run-all.sh` 对安全子集做快速回归。
4. 用 `反馈.md` 和 `经验.md` 把运行时差异、文档缺口、agent 编码经验回流给 skill 上游。
