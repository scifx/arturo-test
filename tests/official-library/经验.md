# Official Library 经验

1. `info.get` 是收集官方默认示例的最佳入口：

```arturo
info.get 'map | get 'example
```

2. 本 runtime 中 `info.get` 需要直接 literal，不能用变量间接传 symbol；因此大规模验证脚本需要生成直接调用代码。
3. “示例存在性验证”和“示例执行验证”应分层：
   - metadata coverage：检查官方示例可发现。
   - curated execution：挑选无副作用、无网络、无 UI 的示例真正执行。
4. 官方示例导出工具不应该负责拉取 skill；skill 的准备和更新由使用者显式执行。
