# colors 经验

来源：https://arturo-lang.io/documentation/library/colors + 实测。

## 网页总章才有的要点

- 颜色字面量：`#f00`、`#ff0000`、`#ff0000ff`、`#red`、`#deepPurple`。
- 分量：`extract.red` / `.green` / `.blue` / `.alpha`；空间：`extract.hsl` / `extract.hsv`。
- 从 HSV 重建：`to :color .hsv [300 1.0 1.0]`。
- `blend` 默认 50/50；`.balance:0.7` 是 70/30。
- `palette.triad` / `.tetrad` / `.split` / `.analogous`。

## 已验证

```arturo
#f00 = #red = #FF0000
darken #red 0.3            ; #B20000
blend #red #blue           ; #800080
invert #red                ; #00FFFF
```

## 坑

- 总章写 `invert #white ; #black`，当前 runtime 是 **`#FFFFFF`**。`invert #red` 才是补色青。不要照抄 white→black。
