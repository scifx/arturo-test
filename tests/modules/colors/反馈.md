# colors 反馈

## 已验证

- hex 短写、命名色、extract、lighten/darken、saturate/desaturate、blend、palette.triad、HSV 往返与总章数字一致。

## 网页与 runtime 不符

- **`invert #white` 文档写 `#black`，实测 `#FFFFFF`。** `invert #black` 仍是 `#000000`。补色对红→青是对的。

## 给 skill 的重点

- 先教 `#red` / `#f00` / `extract.red`，再教 HSL/HSV。
- `invert` 不要用白/黑当唯一例子。
