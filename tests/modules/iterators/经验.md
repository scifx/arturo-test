# iterators 经验

来源：https://arturo-lang.io/documentation/library/iterators + 实测。

## 网页总章才有的要点

- `loop` / `map` / `select` / `filter` 对 block、dict、string、range 同一套。
- `select` 留下谓词为真的；`filter` 丢掉谓词为真的。
- `=>` 简写：`map 1..5 => [& ^ 2]`。
- `fold.seed: 100` 才有种子；无种子时 `fold 1..5` 求和是 15。

## 已验证

```arturo
map 1..5 'x [x * 2]                ; [2 4 6 8 10]
select 1..10 'n [even? n]          ; [2 4 6 8 10]
filter 1..10 'n [even? n]          ; [1 3 5 7 9]
every? [2 4 6 8] => even?
enumerate [2 4 6 8] 'x [x > 5]     ; 2
gather words 'w [first w]
cluster temps 't [t]
chunk 1..6 => [& < 3]
```

## 网页错误

- `enumerate [2 4 6 8] 'x -> x > 5` 文档写 `; => 3`，实测是 **2**（只有 6 和 8）。
