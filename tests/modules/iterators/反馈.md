# Iterators 反馈

## 已验证

- `map 1..5 'x [2 * x]` 返回 block。
- `map 'arr 'x [...]` 会就地改写 `arr`。
- `select 1..6 'x [even? x]` 返回满足条件的 block。
- `map.with:'i` 可以暴露从 `0` 开始的索引变量。

## 可反馈给 skill 的点

- `map` 同时支持返回新 block 与就地修改 literal target；示例应明确区分这两类行为。
- `map.with:'i` 的索引从 `0` 开始，这对从 Python/JS 迁移者友好，但需要文档确认。
