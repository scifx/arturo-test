# numbers 经验

来源：官方网页总章 https://arturo-lang.io/documentation/library/numbers （CLI 没有这篇导读），以及本仓库实测。

## 网页总章才有的要点

- 这是“比 arithmetic 更进一步”的数学库：三角、对数、数论、复数为模/幅角。
- **`epsilon` 在 Arturo 里是 e（2.718…），不是机器精度。** 总章写明，且 `epsilon = exp 1`。
- `tau` = `2 * pi`。`infinite` 打印为 `∞`。
- 复数：`to :complex [3 4]` → `3.0+4.0i`。`abs z` 是模，`angle z` 是幅角。
- `pi / 6` 因为 `pi` 是 `:floating`，`/` 按浮点除，等于 `pi // 6`。

## 已验证片段

```arturo
hypot 3 4              ; 5.0
abs to :complex [3 4]  ; 5.0
angle to :complex [3 4]
round.to: 2 sin pi / 6 ; 0.5
factors.prime 12       ; [2 2 3]
gcd [24 36]            ; 12
```

## 和 arithmetic 的分工

- 四则、幂、商余、正负：`arithmetic`
- 三角、对数、取整、数论、常数、hypot：`numbers`
- 矢量项目用 `hypot` / `sqrt` / `//`，不把 `/` 当实数除。
