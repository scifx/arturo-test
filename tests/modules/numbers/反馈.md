# numbers 反馈

## 已验证

- 网页总章的常数、`exp`/`ln`/`log`、`ceil`/`floor`/`round`、`hypot`、`factors`/`gcd`/`lcm`、`prime?`、`sin pi/6` 在 `0.10.1-dev+43` 上成立。
- **`angle` 当前 runtime 可以解析**（`angle to :complex [3 4]` 返回 floating）。旧报告里“`angle` 无法解析”已过时。
- `epsilon` = `exp 1` ≈ 2.718，不是 IEEE machine epsilon。

## 可反馈给 skill 的点

- 必须写清：`epsilon` 是自然对数的底。从 Python 来的人会当成 `sys.float_info.epsilon`。
- `info.get 'epsilon` / `info.get 'pi` 的 example 字段是空的，只能靠网页总章或实测。
- 总章把 Numbers 定位成 arithmetic 之上的 advanced math，skill 索引应按这个分，不要混成一个“数学”袋。
- `angle` 应重新标成可用，不要继续当 gap。
