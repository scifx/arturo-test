# system 经验

来源：https://arturo-lang.io/documentation/library/system + 实测。

## 已验证

- `sys\os`、`sys\cpu\arch` 的类型是 **`:literal`**，不是 `:string`。本环境是 `linux` / `amd64`。
- `process\id` 是 `:integer`。
- `env` 是 dictionary，`key? env 'HOME`。
- `path\current` / `\home` / `\temp` 是 string。
- `superuser?` 返回 logical。
- `standalone?` 在作为主脚本运行时为 true。

## 不要在回归里跑

- `exit` / `panic` / `execute.async` 长进程。
- 总章里的 `execute "ls -l"` 依赖环境。
