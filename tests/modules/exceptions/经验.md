# exceptions 经验

来源：https://arturo-lang.io/documentation/library/exceptions + 实测。

```arturo
err: try [discard 10 / 0]
error? err          ; true
throws? [discard 10 / 0]
throw "boom"
```

网页写 `err: <= try [...]`。`<=` 在本仓库是 comparison 的 `greaterOrEqual?` 的反写……不对，`<=` 不是合法小于等于（小于等于是 `=<`）。总章里的 `err: <= try` 是 **dup/pipe 赋值糖**（`dup` 的 `<=`），不是比较。未在本章测试里依赖这种写法，回归用 `err: try [...]`。
