# Core 经验

1. 写 Arturo 前先查字典：`info 'name` 或 `info.get 'name`。
2. 需要把变量名传给函数时使用 literal：`'x`；读取用 `var 'x`，写入用 `let 'x value`。
3. 块 `[...]` 默认是数据；只有 `do block` 或函数按 action 参数消费时才执行。
4. 属性不是 kwargs，而是属性栈；用户函数要消费属性，至少保留一个参数占位，调用时传 `null`。
5. 默认参数推荐模板：

```arturo
default: function.inline [name value][
    let name ((attr name) ?? value)
]
```

## 网页总章（https://arturo-lang.io/documentation/library/core）

- 赋值：`x: 5`。多值解包用 `[a b c]: [1 2 3]`，**不要**写 `[a,b,c]: 1,2,3`。
- 分支：`if`、`switch` / `?`、`case` + `any`、`when`。
- `??` 是 coalesce：`null ?? "default"`。
- 函数：`function` 或 `$[n][n * 2]`。
- 逻辑长链用 `and?` / `not?` 并加括号：`and? (2 > 1) (3 > 2)`、`not? (2 = "2")`。
- `and` 是 bitwise，吃 integer。`and?` 吃 logical/block。`and? 42 8` 会 Type Error。

## 模块化（来自 `tests/projects/vector-math` 实测）

`\name` 是 `this\name` 的简写。**声明字段和调用兄弟时写成 `this\name`。**

```arturo
box: module [
    bang: function [s :string][ ~"|s|!" ]
    greet: method.public [name :string][
        this\bang ~"hi |name|"
    ]
]
export box!
```

模块体顶层没有 `this`，不能写 `this\bang: function [...]`。字段声明仍用 `bang: function [...]`；`init` / method 里赋值才写 `this\ops: ...`。

### 外部函数 + 模块 ≈ Python `__init__.py`

```arturo
vector: module.with: [] [
    init: method [][
        this\ops: import.lean ./{ops}!
    ]
    vecAdd: method.public [left :block right :block][
        map couple left right 'p [
            this\ops\pairAdd p
        ]
    ]
]
export vector!
```

`import.lean` 返回 dictionary，不污染文件全局。

### 作用域上踩过的坑

1. method 里直接 `import ./{ops}!` 时，导入函数 arity 常丢失。
2. `import.lean` 会隔离被导入文件，helper 必须自包含。
3. 文件顶层 `import ./{ops}!` 会泄漏符号。
4. 公开方法不要叫 `add` / `sub` / `div`。
5. `standalone?` 在被 `import` 的文件里是 false。
6. `export.all` 会把私有方法也导出。
