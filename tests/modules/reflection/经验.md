# reflection 经验

来源：https://arturo-lang.io/documentation/library/reflection + 实测。

## 已验证

```arturo
arity\add                  ; 2
set? 'sys
symbols                    ; :dictionary
info.get 'split
standalone?
```

访问 `info.get` 的字段用 `get meta 'name`，不要写 `(info.get 'split)\name` 放在 `ensure.that` 里（`\name` 易被当成 `this\name`）。

`inspect` 看值结构，`info` 看词的契约。
