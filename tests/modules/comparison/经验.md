# comparison 经验

来源：https://arturo-lang.io/documentation/library/comparison + 实测。

## 网页总章才有的要点

- 小于等于是 **`=<`，不是 `<=`**。
- `<=>` 是 **闭区间 between**，不是三路比较符号本身当 spaceship 用在两个值上……等一下，也有 `compare` 返回 -1/0/1。
- `5 <=> 1 10` 等价 `between? 5 1 10`。
- `=` 比的是值；`same?` 比的是同一性。`1`N = 1`kg.m/s2` 为 true，`same?` 为 false。
- `2.0 <> 2` 为 false（会提升后相等）。
- `2 = "2"` 为 false。

## 已验证

```arturo
2 =< 2
5 <=> 1 10
compare "hello" "world"    ; neg 1
same? 1`N 1`kg.m/s2        ; false
```
