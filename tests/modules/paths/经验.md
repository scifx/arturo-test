# paths 经验

来源：https://arturo-lang.io/documentation/library/paths + 实测。

## 网页总章才有的要点

- `extract` 既能拆文件路径，也能拆 URL。
- **`extract.port` 返回的是字符串 `"8080"`，不是整数 8080。**
- `normalize "./folder/../file.txt"` → `file.txt`。
- `normalize.tilde "~/code"` 会展开家目录。
- `./\"some/file.txt\"` 等价 `relative`。

## 已验证

```arturo
extract.directory "photos/vacation/beach.jpg"    ; photos/vacation
extract.filename  "photos/vacation/beach.jpg"    ; beach
extract.host "https://example.com:8080/x"        ; example.com
extract.port "https://example.com:8080/x"        ; "8080"
```
