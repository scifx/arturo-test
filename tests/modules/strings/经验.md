# strings 经验

来源：https://arturo-lang.io/documentation/library/strings + 全量实测（5 个 .art 文件，~100 条断言）。

## 网页总章才有的要点

- 多种字面量：`"..."`、`{...}`、`{:...:}`（verbatim）、`« ...`（right smart-quote）、heredoc（`------`）。
- 拼接只用 `++` 接两个 string。
- `~"|name|"` 会 **执行** `|` 里的代码，是求值不是纯替换。
- `render.template` 用 `<|| ... ||>` 语法，支持条件 (`<||= ...? [||>..<||][||>..<||]||>`) 和循环 (`<|| loop ... [||>..<||]||>`)。
- 正则用 `{/\d+/}`（brace 包 slash），不要写 `/.../`（那是除法）。
- `split "ab"` 返回 **string** `["a" "b"]`（不是 `:char`）。
- `alphabet 'es` 返回 **`:char`** 数组（不是 `:string`），要查元素用 `in? (first "ñ") alphabet 'es`。

## 和网页/runtime 不一致

| 条目 | 网页写法 | runtime 实测 |
|---|---|---|
| `suffix?` 正则 | `suffix? "hello" {/\w/}` → true | **不支持**，返回 false |
| `match` 返回值 | 写成 `"o world"` | 返回 **block** `["o world"]` |
| `truncate ... 5` | `Hello...`（无空格） | **`Hello ...`**（点前有一个空格） |
| `pad.with:`0` ` | `` 0` 当作 `:char` | ＊`0` **是 `:unit`**，不可直接给 pad.with；要用 `first "0"` 转 `:char` |
| `prefix?` 正则 | 支持 | 支持（唯一带 regex 的前后缀谓词） |

## 数值写法约定

- 负数用 `neg N`，不要写 `-N`（`-1` 在参数位置会解析为负整数后传递给 attribute）。例如 `truncate "Hi" (neg 3)` → `"Hi..."`。
- 比较长链用括号：`(truncate "Hello" 5) = "Hello ..."`，否则解析器会错绑。

## 给 skill 的重点

1. 先讲**字面量**：`""`, `{}`, `{: :}`, `«`, heredoc。
2. `~` 是求值插值，`render.template` 是块模板引擎——两者不同。
3. 正则必用 `{/.../}`。
4. 谓词 `prefix?` 支持 regex，`suffix?` 不支持——传 regex 静默返回 `false`。
5. `pad.with` 需要 **`:char`**——`first "0"` 而不是 `` `0` ``。
6. `match` 全家桶返回均为 `:block`（包括单匹配）。
7. `truncate` 的省略号标记前默认有一个空格；`.preserve` 模式会到单词边界才切。
8. `escape.shell` 只在字符串含特殊字符时加引号。

## 对 collections 的交叉参考

- `contains?` / `match?` / `in?` 参数顺序与 collections 一致。
- 字符串下标 `str\0` 返回 `:char`，改字符用 `str\0: "X"`。
- `slice` 对字符串直接可用（不须 `@`），对 range 须 `@1..10`。
