# strings 经验

来源：https://arturo-lang.io/documentation/library/strings + 实测。

## 网页总章才有的要点

- 多种字面量：`"..."`、`{...}`、`{:...:}`、`« ...`。
- 拼接只用 `++` 接两个 string。
- `~"...|name|..."` 会 **执行** `|` 里的代码。
- 正则用 `{/\d+/}`，不要写 `/.../`（那是除法）。

## 已验证

```arturo
upper "hello"                      ; HELLO
prefix? "hello" "he"
strip " hello  "                   ; hello
~"Hello |name|!"
replace "Date: 2024" {/\d+/} "2025"
match "hello world" {/o(.+)d/}     ; ["o world"]  ← block
truncate "Hello World" 5           ; "Hello ..."
upper? "HELLO"                     ; true（当前 runtime 有此谓词）
```

## 和网页不一致

- `match` 文档写成字符串 `"o world"`，实测是 **block** `["o world"]`。
- `truncate ... 5` 文档 `Hello...`，实测 **`Hello ...`**（点前面有空格）。
