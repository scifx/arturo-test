## 网页 / info.get 与 runtime 不符

### 1. `suffix?` 不支持正则

官方文档和 `info.get` 示例包含 `suffix? "hello" {/\w/}`，但 runtime 返回 `false`。  
`prefix?` 的正则支持正常。

### 2. `match` 返回值类型

官方 `match "hello world" {/o(.+)d/}` 在文档页和 info 中写成 `"o world"`（字符串），  
但 runtime 返回 block `["o world"]`。所有 match 变体（match.once、match.capture 等）都返回 `:block`。

### 3. `truncate` 省略号前有空格

`truncate "Hello World" 5` → `"Hello ..."`（空格 + 三点），但官网示例写 `"Hello..."`。  
`.preserve` 模式才无空格。

### 4. `` `x` `` 是 `:unit`，不是 `:char`

当前 runtime 中 `` `0` `` 是 `:unit`（quantity），不是 `:char`。  
`pad.with:`0` ` 会 TypeError。应使用 `pad.with: (first "0")` 传入 `:char`。  
改字符串字符用 `s\0: "X"` 或 `first "X"`。

### 5. `escape.shell` 不加多余引号

对纯字母字符串 `escape.shell "hello"` 返回 `"hello"`（无异），只在含特殊字符时才加单引号。

## 给 skill 的重点

- strings 是 Arturo 最常用的模块——字面量语法、`~`插值、`render.template`、正则的 `{/.../}` 语法必须讲清楚。
- 谓词返回值都是 `:logical`，所有 match 变体返回 `:block`。
- `pad.with`、`truncate.with` 等 attribute 走 `.属性:` 语法。
- `escape` 家族每个子类型输出格式不同（json/regex/shell/xml）。
- `jaro`、`levenshtein` 返回 `:floating`，算是库里的隐藏彩蛋。
- `translate` 和 `replace` 的 block/paired 模式容易混淆。
