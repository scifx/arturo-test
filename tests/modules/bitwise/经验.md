# bitwise 经验

来源：https://arturo-lang.io/documentation/library/bitwise + 本仓库实测。

## 网页总章才有的要点

- 只对 **integer** 做位运算，结果仍是 integer。
- `not` 是二进制补码，不是逻辑非：`(not 5) = neg 6`。源码里不能写 `-6`，要写 `neg 6`。
- `shl n k` ≈ `n * (2^k)`，`shr n k` ≈ `n / (2^k)`（整数）。
- **不要和 logic 搞混：** 位运算是 `and`/`or`/`not`（吃 integer）。逻辑是 `and?`/`or?`/`not?`（吃 logical/block）。`and? 42 8` 会 Type Error。查 bit 用 `(and 42 (shl 1 3))`。

## 已验证

```arturo
and 5 3          ; 1
or 5 3           ; 7
xor 5 3          ; 6
shl 8 2          ; 32
shr 8 1          ; 4
and 42 (shl 1 3)   ; 8  — bit 3 of 42
```

置位/清位（总章写法，右到左碰巧成立）：

```arturo
number: or number (shl 1 pos)
number: and number (not shl 1 pos)
```
