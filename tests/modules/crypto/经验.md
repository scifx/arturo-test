# crypto 经验

来源：https://arturo-lang.io/documentation/library/crypto + 实测。

## 已验证

```arturo
digest "hello world"           ; 5eb63bbbe01eeed093cb22bb8f5acdc3
digest.sha "hello world"       ; 2aae6c35c94fcfb415dbe95f408b9ce91ee846ed
crc "hello world"              ; 0D4A1185   （大写）
encode "Hello World!"          ; SGVsbG8gV29ybGQh
decode encoded
encode.url.spaces "hello world"    ; hello%20world
encode.url.slashes "/path/to/resource"
```

## 和网页不一致（以 runtime 为准）

- `crc` 网页写小写 `0d4a1185`，这里是 **大写** `0D4A1185`。
- `encode.url` 默认：空格变成 `+`，斜杠 **不** 编码。网页示例写成 `%20` 和 `%2F` 是错的。
- 要 `%20` 用 `encode.url.spaces`；要编码 `/` 用 `encode.url.slashes`。
