# crypto 反馈

## 网页与 runtime 不符

1. `crc "hello world"` 文档 `0d4a1185`，实测 `0D4A1185`。
2. `encode.url` 文档把空格写成 `%20`、把 `://` 的斜杠写成 `%2F`。实测是 `https%3A//example.com/path+with+spaces%3Fq%3Dtest%2B1`。

## 给 skill 的重点

- 默认 `digest` 是 MD5；SHA1 要 `digest.sha`。
- URL 编码三个层次：`encode.url` / `.spaces` / `.slashes` 不要混。
- 总章 Password Hashing 只是示例，不是安全建议。
