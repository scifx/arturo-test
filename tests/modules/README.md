## 已有可执行测试的第一批分区

| 分区 | 重点 |
|---|---|
| `core/` | `info.get`、`var`、`let`、`do`、属性栈、默认参数 helper |
| `collections/` | block/dictionary 变更、`sort`、`append`、`key?`、`get`、`set` |
| `strings/` | 大小写、切分、替换、正则匹配 |
| `iterators/` | `map`、`map.with`、`select` |
| `files/` | `write`、`read`、`write.json`、`read.json` |

新增或完善分区时保持同样的三份 Markdown 文档：`README.md`、`反馈.md`、`经验.md`。
