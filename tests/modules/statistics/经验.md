# statistics 经验

来源：https://arturo-lang.io/documentation/library/statistics + 实测。

## 网页总章才有的要点

- 吃 block 或 range：`average 1..100` = 50.5。
- 默认是 **总体** 统计；样本加 `.sample`。
- 返回值按总章说是 floating。`median` 对奇数个整数样本可以仍是整数 `3`。
- 总体标准差/方差会有 IEEE 毛刺：`deviation [2 4 4 4 5 5 7 9]` 是 `1.999...` 不是干净的 `2.0`。断言用容差或 `round`。

## 已验证

```arturo
average [1 2 3 5 7]            ; 3.6
median [1 2 3 5 7]             ; 3
deviation.sample numbers
round.to:3 skewness data       ; 0.0
round.to:3 kurtosis data       ; -0.75
```
