# statistics 反馈

## 已验证

- 总章平均数、中位数、样本标准差/方差、偏度峰度（round.to:3）与 runtime 一致。

## 网页 / runtime 差异

- `deviation numbers ; 2.0` 实测 `1.9999999999999998`。
- `variance numbers ; 4.0` 实测 `3.9999999999999996`。
- skill 不要对总体方差/标准差写精确 `= 2.0`。

## 给 skill 的重点

- 默认总体、`.sample` 才是样本，必须写清。
- `median` 不一定返回 floating。
