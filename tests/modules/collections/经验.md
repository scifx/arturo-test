# collections 经验

来源：https://arturo-lang.io/documentation/library/collections + 实测。

## 网页总章才有的要点

- block / dictionary / string / range 共用很多操作。
- 原地修改传 literal：`'lst ++ 4`、`'lst -- 2`。
- 下标从 0：`lst\2` 是第三个。动态下标 `colors\[pos]`。
- dictionary 保序。`user\name`；动态键 `user\[field]`。
- `contains? dict "John"` 查的是 **值**，不是键。查键用 `key?`。
- `@range` 才物化。`2..5` 物化后是 `[2 3 4 5]`（两端都含）。
- 字符串按 Unicode 字符计：`size "Hello 世界"` = 8。

## 网页与 runtime

- `index [1 2 2 3 3 3] 3` 文档写 2，实测 **3**。
- `nums: 1..1000` 然后 `nums\42` 文档写 42，实测 **43**（0 号是 1）。
- 总章 `[a,b,c]: 1,2,3` 这种逗号写法不能当元组解包用。应写 `[a b c]: [1 2 3]`。
