# collections 经验

来源：https://arturo-lang.io/documentation/library/collections + 全量实测。数组是 `:block`，字典是 `#[...]`。水很深，下面每条都跑过。

## 别名和拷贝

```arturo
a: [1 2 3]
b: a
c: new a
'b ++ 9          ; a 也变成 [1 2 3 9]
                 ; c 仍是 [1 2 3]
```

`extend` 字典会拷贝，改副本不会改原件。

## 原地修改必须传 `'xs`

```arturo
'lst ++ 4
'lst -- 2
append 'lst 4
sort 'lst
pop 'lst
empty 'lst
```

不传 literal 就返回新值，原变量不动。

## 下标从 0

- `lst\2` 是第三个。
- 动态下标：`lst\[i]`，动态字典键：`user\[k]`。
- **`user\w` 不会用变量 w**，它找字面字段 `w`，没有就 Index Error。
- `1..1000` 的 `\42` 是 **43**（0 号是 1）。网页写成 42 是错的。

## couple / decouple

```arturo
couple ["one" "two"] [1 2]
; [["one" 1] ["two" 2]]     第一个集合在前
decouple that
; [["one" "two"] [1 2]]
```

官方 `info.get` 注释写成 `[[1 "one"] ...]`，与 runtime 相反。

## 字典：get / set / key? / contains?

| 需求 | 写法 |
|---|---|
| 静态字段 | `user\name` |
| 动态键 | `get user k` / `set user k v` / `user\[k]` |
| 键在不在 | `key? user k`（`'name` 和 `"name"` 都行） |
| 值在不在 | `contains? user "John"` 或 `in? "John" user` |
| 键名当字符串找 | `in? "name" keys user` |

`contains? user "name"` 是 false：它不查键名。

词频模板：

```arturo
current: (key? freq w)? [get freq w] [0]
set freq w (current + 1)
```

## insert 字典

`insert 'dict 'name "Jane"` **会 Type Error**（index 要 `:integer` 或 `:string`）。  
改键用 `set`；`insert 'dict "extra" "ok"` 可以加新字符串键。

## slice / range

`slice 1..10 3 4` 对裸 range 报 Type Error。先物化：`slice (@1..10) 3 4` → `[4 5]`。

## chop / drop / take 的负数

- `chop.times: (neg 1)` 从 **前面** 去掉。
- `drop.times: (neg 1)` 从 **后面** 去掉。
- `take xs (neg 2)` 取末尾两个。

源码写 `neg 1`，不要写 `-1`。

## 字符不是 `` `x` ``

当前 runtime 里 `` `x` `` 是 **:unit**（quantity），不是 char。  
`first "X"` 才是 `:char`。改字符串第 0 个用 `s\0: "X"`。  
`split "ab"` 得到的是 **string** `"a"` `"b"`，不是 char。

## 其它已验证

- `@[b b+1 b+2]` 会求值；`array.of: [2 3] 0` 是 2×3 零阵。
- `dictionary.with: [entity][...]` 把外部 `entity` 收进字典。
- `#.lower [Name: "John"]` 键变成 `name`。
- `tally "hello"` 用 `get t "l"` 取值。
- `remove.once` / `remove.key` / `remove.prefix` / `remove.suffix` 可用。
- 嵌套：`select users\active 'u [and? (contains? u\tags "admin") (u\score > 40)]`。
