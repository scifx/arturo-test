# Collections 经验

1. 需要原地修改 collection 时，通常传 literal：`sort 'xs`、`append 'xs 4`。
2. 动态 key 不要写成 `dict\k`；优先使用：

```arturo
current: (key? freq w)? [get freq w] [0]
set freq w current + 1
```

3. block 可以直接用 `=` 做回归断言：`ensure [xs = [1 2 3]]`。
4. 两个 block 逐项配对用 `couple a b`，当前 runtime 得到 `[[a0 b0] [a1 b1] ...]`。
5. 负数不要写成 `[-1 2]`；应使用求值 block：`@[neg 1 2]`。
