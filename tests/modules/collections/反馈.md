# collections 反馈

## 已验证

- 创建、`++`/`--` 原地改、`first`/`last`、下标、dict 字段、flatten/unique/reverse、combine.by、range first/last、Unicode size。
- `contains? user "John"` 当前可用（查值）。旧 raw 示例里的 `contains? dict "John"` 失败，是因为变量名是 `user` 不是 `dict`。

## 网页错误

- `index data 3` 注释 2，应为 3。
- `1..1000` 的 `\42` 注释 42，应为 43。

## 给 skill 的重点

- 0 基下标。
- `contains?` vs `key?` vs `in?`。
- 不要教 `1,2,3` 解包。
