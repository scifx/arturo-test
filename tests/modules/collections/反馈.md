# Collections 反馈

## 已验证

- `sort 'xs` 会通过 literal 修改原 block。
- `append 'xs value` 会修改原 block。
- dictionary 动态字符串 key 应优先使用 `get dict key` / `set dict key value` / `key? dict key`。

## 可反馈给 skill 的点

- `freq\\w` 容易被误解为动态 key；实际这里更适合使用 `get/set`，否则可能访问字面字段 `w`。
- 示例应明确区分：`dict\\name`（静态字段）与 `get dict name`（动态 key）。
- 官方 `couple` 示例注释写成 `[[1 "one"] [2 "two"] ...]`，当前 runtime 实际是 `[["one" 1] ["two" 2] ...]`（第一个集合在前）。`tests/projects/vector-math` 已按 runtime 使用。
- `[-1 2]` 会被 parse 成 symbol `-` 加两个整数，不是含 `-1` 的 block。数值矢量应写 `@[neg 1 2]`。
