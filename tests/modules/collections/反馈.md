## 网页 / info.get 与 runtime 不符

1. **`couple` 示例注释顺序反了。** runtime 是 `[first0 second0]`。
2. **`contains? dict "John"`** 示例里变量叫 `user` 却写成 `dict`。语义是查值。
3. **`insert 'dict 'name "Jane"`** 当前要求 index 为 integer/string，literal 键报 Type Error。
4. **`slice 1..10 3 4`** 不接受 `:range`，要 `@1..10`。
5. **`index [1 2 2 3 3 3] 3`** 总章写 2，实测 3。
6. **`(1..1000)\42`** 总章写 42，实测 43。
7. **`str\0: \`x\``** 当前 `` `x` `` 是 unit，不是 char。
8. **`[a,b,c]: 1,2,3`** 不能解包。

## 给 skill 的重点

- 先讲别名/`new`、`'xs` 原地改、0 基下标、`get/set/key?` 动态键。
- `contains?` / `key?` / `in?` 参数顺序和查值/查键必须分开。
- 负数下标和 times 一律 `neg N`。
- 长链加括号：`set freq w (current + 1)`。
