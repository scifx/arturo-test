# arithmetic 经验

来源：官方网页总章 https://arturo-lang.io/documentation/library/arithmetic （CLI `info` 没有这篇导读），以及本仓库 runtime 实测。

## 网页总章才有的要点

- 同一套 `+ - * / //` 覆盖 integer / floating / rational / complex / quantity。
- 不同类型会自动提升到更“宽”的类型：`5 + 3.41` → `:floating`，`3 + 1:2` → `:rational`。
- 原地修改必须传 literal：`inc 'x`、`add 'x 3`。`inc x` 只返回新值，不改 `x`。
- `1:2` 是有理数字面量 `1/2`，不是切片。

## 运算符对照

| 前缀 | 中缀 | 含义 | 实测 |
|---|---|---|---|
| `add` | `+` | 加 | `2 + 3` = 5 |
| `sub` | `-` | 减 | `5 - 3` = 2 |
| `mul` | `*` | 乘 | `4 * 3` = 12 |
| `div` | `/` | **整数**除 | `10 / 3` = 3，`3 / 5` = 0 |
| `fdiv` | `//` | 浮点除 | `10 // 3` ≈ 3.333，`3 // 5` = 0.6 |
| `mod` | `%` | 模 | `5 % 2` = 1 |
| `divmod` | `/%` | 商和余数 | `[q r]: 10 /% 3` |
| `pow` | `^` | 幂 | `2 ^ 3` = 8 |
| `inc` / `dec` / `neg` | （无常用中缀） | +1 / -1 / 变号 | `inc 'x` |

## 必须记住

1. **整数除法 `/` 会截断。** 归一化、速率、比例一律用 `//`。来源：总章 Basic Operations + 本仓库矢量项目。

2. **没有运算符优先级，右到左。** `2 + 3 * 5` 碰巧是 17；`3 * 5 + 2` 是 **21**。要 17 必须写 `(3 * 5) + 2`。

3. **比较式包住算术。** `1:2 + 3:4 = 5:4` 会变成 `1:2 + (3:4 = 5:4)`。写成 `(1:2 + 3:4) = 5:4`。

4. **quantity 加减一个数是改大小。** `3`m + 10` 实测是 `13 m`，不是文档写的 `3 m`。`2`m * 3`m` 得到面积 `6 m²`。`fdiv 100`m 5`s` 得到 `20 m/s`。

5. **公开 method 不要叫 `add`/`sub`。** `export` 后会盖住这里的 builtin。见 `tests/modules/core/经验.md`。

6. **`[-1 2]` 不是负数。** 变号用 `neg`，矢量里写 `@[neg 1 2]`。
