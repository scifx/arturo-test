# arithmetic 反馈

## 已验证（网页总章 + runtime）

- 11 个函数的 `info.get` 示例可整模块跑通（`official-examples-smoke.art`）。
- 总章里的类型提升、`1:2` 有理数、`inc 'x` 原地修改、quantity 乘除，与 `arturo 0.10.1-dev+43` 一致。
- `add` 还接受 `:color` / `:date`：`#FF0000 + #0000FF` = `#FF00FF`。
- `/` 对负数：`((neg 5) / 2) = neg 2`。

## 网页总章与 runtime 不符（应反馈 skill / 文档）

1. **`y: 2 3:4 ; 3/2` 是错的。**  
   `y: 2 3:4` 只把 `y` 绑成整数 `2`，`3:4` 是另一段值。要 `3/2` 应写 `2 * 3:4`。

2. **`q: 3`m + 10 ; 3 meters` 是错的。**  
   实测 `13 m`。同页的 `3`m - 2` → `1 m` 是对的，说明 `+ 10` 的注释抄错了。

3. **CLI `info` 没有模块总章。**  
   类型提升、quantity 模式、`1:2` 语法只出现在网页 https://arturo-lang.io/documentation/library/arithmetic 。skill 若只喂 `info.get` 会漏掉这些。

4. **`2 + 3.81` 文档写 `5.81`，IEEE 结果是 `5.8100000000000005`。** 断言应用 `floating?` 或容差，不要精确相等。

## 给 skill 抓的重点

- 先讲 `/` vs `//`，再讲右到左，再讲 `'x` 原地修改。
- 有理数用 `1:2`，不要发明 `to :rational` 当唯一写法。
- 从网页总章抽例子前必须跑一遍；至少上面两条是错的。
