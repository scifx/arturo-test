# types 经验

来源：https://arturo-lang.io/documentation/library/types + 实测。

## 网页总章才有的要点

- `type x` 返回 `:integer` 这类 type 值。
- 谓词：`integer?` / `string?`；也可用 `is? :integer x`。
- 转换：`to :string` / `to :integer` / `to :floating` / `to :date .format:`。
- 自定义类型：`define :person [ init: method ... string: method ... ]`，构造 `to :person ["John" 38]!`。
- 方法里 `\name` 就是 `this\name`。总章 Tip 写的和模块课题一致。

## 已验证

```arturo
type 42                    ; :integer
is? :integer 42
to :integer "42"
define :person [ ... ]
john: to :person ["John" 38]!
to :string john            ; John (38 years old)
```

继承 / `super` / magic methods 表还没在本仓库逐条跑。
