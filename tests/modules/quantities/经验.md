# quantities 经验

来源：https://arturo-lang.io/documentation/library/quantities + 实测。

```arturo
3`m
5`km --> `m                 ; 5000 m
90`km/h --> `m/s            ; 25 m/s
25`degC --> `degF           ; 77°F
(5`m) + (3`km --> `m)       ; 3005 m
(100`km/h) * 2.5`h          ; 250 km
length? 3`m
area? (2`m * 3`m)
scalar 3`m                  ; 3
property 5`m                ; length :literal
conforms? 3`m 10`cm
(1`N) = 1`kg.m/s2
```

`property` 返回 `:literal`，不是 string。货币换算依赖汇率，不要写死断言。
