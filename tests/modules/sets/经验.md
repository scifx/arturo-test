# sets 经验

来源：https://arturo-lang.io/documentation/library/sets + 实测。

## 网页总章才有的要点

- 集合就是 block，重复元素会按集合语义处理。
- `subset?.proper` 才是真子集（不能相等）。
- `difference.symmetric` 是对称差。
- `powerset [1 2 3]` 含空集和自身，顺序为实测：`[[] [1] [2] [1 2] [3] [1 3] [2 3] [1 2 3]]`。
- 多集合：`fold sets => union` / `intersection`。

## 已验证

```arturo
union [1 2 3 4] [3 4 5 6]              ; [1 2 3 4 5 6]
difference.symmetric A B               ; [1 2 5 6]
fold [[1 2] [2 3] [3 4]] => intersection   ; []
```
