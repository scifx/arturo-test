# logic 经验

来源：https://arturo-lang.io/documentation/library/logic + 实测。

## 网页总章才有的要点

- 三值逻辑：`true` / `false` / `maybe`。`true? maybe` 的结果是 **`maybe`**，不是 false。
- `and? true maybe` → `maybe`；`or? true maybe` → `true`。
- **短路：** 把条件写成 block。`and? [1=2][print "no"]` 不会跑第二块。
- 一次判断多个值用 `all?` / `any?`，可吃 block。
- 逻辑谓词都带 `?`：`and?` / `or?` / `not?`。不带 `?` 的 `and`/`or`/`not` 是 bitwise，**不能**写成 `and? 42 8`（要 `:logical` 或 block）。
- 长链逻辑式加括号：`and? (2 > 1) (3 > 2)`、`not? (2 = "2")`。

## 已验证

```arturo
and? [1 = 2][print "never"]     ; 第二块不执行
or?  [1 = 1][print "never"]     ; 第二块不执行
all? @[true false true]         ; false
any? @[true false true]         ; true
```
