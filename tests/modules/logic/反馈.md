# logic 反馈

## 已验证

- 总章三值逻辑、短路、`all?`/`any?`、`nand?`/`nor?`/`xnor?` 与 runtime 一致。
- 官方 `官方示例.md` 里仍有整模块解析失败的片段，所以默认回归用 `chapter-overview.art`，不跑 raw smoke。

## 给 skill 的重点

- `maybe` 和 `true? maybe => maybe` 必须写进 skill，否则会按二值逻辑猜。
- 短路只对 **block 参数** 成立；写成 `and? false (print "x")` 可能仍求值。
- 和 bitwise 的命名对照表要放一起。
