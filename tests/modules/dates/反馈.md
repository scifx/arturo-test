# dates 反馈

## 已验证

- `now` 字段、`after`/`before`、`leap?` 2024、`future?`/`past?`/`today?`、`to :date .format` / `to :string .format` 可用。

## 网页笔误 / 环境差

- 总章 `print current\day]`、`print current\hour]` 多了一个 `]`。
- 解析示例写 `+01:00`，本 sandbox 是 `+00:00`。skill 不要把时区偏移当固定值。
- `leap? today\year` 随当前年变化，回归里应写死 `leap? 2024`。

## 给 skill 的重点

- 格式模式表只在网页总章，必须收录 `yyyy-MM-dd` / `HH:mm:ss`。
- 日期当 dictionary 用 `\year` 访问。
