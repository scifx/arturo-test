# dates 经验

来源：https://arturo-lang.io/documentation/library/dates + 实测。

## 网页总章才有的要点

- `now` 返回 `:date`，字段用反斜杠：`current\year`、`\month`、`\day`、`\hour`。
- 网页把 `current\day]` / `current\hour]` 多写了一个 `]`，那是笔误。
- 加减：`after.days:7 date`、`before.months:1 date`，可叠 `.hours:2 .minutes:30`。
- 谓词：`future?` / `past?` / `today?` / `leap?` / `monday?` …
- 格式化与解析（总章表格 CLI 没有）：

```arturo
to :string .format:"yyyy-MM-dd" dt
to :date .format:"yyyy-MM-dd" "2024-03-15"
```

## 已验证

```arturo
leap? 2024                         ; true
future? after.days:1 now           ; true
today? now                         ; true
to :date .format:"yyyy-MM-dd" "2024-03-15"
```

解析结果带时区，本环境是 `2024-03-15T00:00:00+00:00`。不要对偏移写死 `+01:00`。
