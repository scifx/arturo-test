# Files / JSON 反馈

## 已验证

- `write` 参数顺序是 `write content file`。
- `write.json payload null` 返回 JSON 字符串，可被 `read.json` 读取。
- `write.json payload path` 与 `read.json path` 可做文件往返。

## 可反馈给 skill 的点

- JSON 示例应推荐 `write.json` / `read.json`，不要臆造 `parse.json` 或 `render.json`。
- `write` 参数顺序容易写反，需要在 skill 的速查表中反复标注。
