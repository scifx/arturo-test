# files 经验

来源：https://arturo-lang.io/documentation/library/files + 实测。

## 网页总章才有的要点

- `read` 会猜来源：路径、URL、或直接当内容。要强制文件用 `read.file`。
- `write content path`；追加 `write.append`。
- JSON：`read.json` 解析字符串或文件；`write.json value null`（或 `ø`）返回 JSON 字符串。
- 回归测试只碰本地 `/tmp`，不要跑总章里的 URL 示例。

## 已验证

```arturo
write "hello" "/tmp/x.txt"
read "/tmp/x.txt"
write.append " more" "/tmp/x.txt"
exists? "/tmp/x.txt"
file? "/tmp/x.txt"
write.json #[a: 1] null
read.json js
delete "/tmp/x.txt"
```

访问 JSON 字段用 `get roundtrip "a"`，不要在 `ensure.that` 块里写 `(read.json js)\a`（`\a` 会被当成 `this\a`）。
