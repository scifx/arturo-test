# vector-math 反馈

## 已验证

- 官方 `module` 可以承载本项目的全部矢量运算：内部 `function` + 对外 `method.public` + `export`。
- `import ./{vector}!` 会执行源文件里的 `export vector!`，调用方直接用 `vecAdd`。
- `if standalone?` 可以区分库自测和被导入。
- `set? 'ensurePair` 为 false：内部 function 不会泄漏。
- 2D 模长用 `hypot`，n-D 用 `sqrt` + 点积；JSON 往返后整数 block 仍是 `:integer`。

## 可反馈给 skill 的点

- skill 的 `module` 章节应写清三件事：内部用 `function`、对外用 `method.public`、兄弟调用写 `\name`。
- 不要把公开方法命名成 `add`/`sub`/`div`；官方示例的 `section`/`greet` 是安全名字，算术名不是。
- `method` 上的 `;; description` 目前几乎挂不上（`info.get` 看到空描述、参数变成 `:any`）。需要文档的 API 用内部 `function`，或接受 method 元数据很弱。
- `[-1 2]` 和 `3 / 5` 这两个坑建议写进 collections/arithmetic recipe。
