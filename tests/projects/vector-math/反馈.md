# vector-math 反馈

## 已验证

- 项目已是官方 `module`：`module.with` + `init` + `method.public` + `export`。
- `\name` ≡ `this\name`。字段赋值和兄弟调用写成 `this\name` 更稳。
- 外部函数可以在 `init` 里 `this\ops: import.lean ./{ops}!`，调用方看不到 `pairAdd`。
- method 体内直接 `import ./{ops}!` 能跑一部分，但导入函数的 arity 不稳定：`unless numericValue? k` 会把 `k` 当成 unless 的 action。
- `import.lean` 后，被导入文件里的兄弟函数互相看不见，helper 必须自包含。

## 可反馈给 skill 的点

- `module` 文档应写：`\name` 就是 `this\name`；声明和调用优先写 `this\name`。
- 包结构 recipe：`ops.art` + `vector.art` 的 `init`/`import.lean`，对标 Python `__init__.py`。
- 不要把公开方法命名成 `add`/`sub`/`div`。
