# vector-math 经验

1. 负数分量不要写进普通 block 字面量：

```arturo
inspect [-1 2]
; [ :block  - :symbol  1 :integer  2 :integer ]

ok: @[neg 1 2]
; [ :block  -1 :integer  2 :integer ]
```

2. 两个等长矢量逐分量运算，先 `couple` 再 `map` / `fold`。当前 runtime 的配对顺序是 `[a0 b0]`：

```arturo
vecAdd: function [a :block b :block][
    map couple a b 'p [
        (get p 0) + get p 1
    ]
]
```

3. 单位矢量必须用浮点除法 `//`。`3 / 5` 是整数除法，结果是 `0`。

4. 逻辑运算用前缀，比较式自己加括号：

```arturo
unless and? (3 = size a) (3 = size b) [
    throw "cross product needs two 3D vectors"
]
```

5. 库文件用 `if standalone?` 包住断言，这样 `import ./{vector}!` 时不会把单元测试跑一遍。

6. 不要把库函数命名成 `add` / `sub` / `div`，会盖住官方 arithmetic 函数。
