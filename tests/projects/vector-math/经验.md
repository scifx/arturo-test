# vector-math 经验

完整模块化规则已浓缩到 [`tests/modules/core/经验.md`](../../modules/core/经验.md)。这里只留本项目会反复踩到的点。

1. 矢量库用官方 `module`：计算写成内部 `function`，对外只 `method.public`，最后 `export vector!`。

2. 模块里调用兄弟函数/方法必须写 `\ensurePair`、`\pairAdd`、`\vecMag`。写成裸名字会在 `export` 时报 `Identifier not found`。

3. 公开方法不要叫 `add` / `sub`。导出会盖住算术 builtin，`(get p 0) + get p 1` 会递归进自己的 `add`。

4. 负数分量用 `@[neg 1 2]`，不要写 `[-1 2]`。

5. 单位矢量用 `//`。`3 / 5` 是整数除法，结果是 `0`。

6. 库文件用 `if standalone?` 包住断言，这样 `import ./{vector}!` 时不会重跑自测。
