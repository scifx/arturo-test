# vector-math 经验

完整模块化规则在 [`tests/modules/core/经验.md`](../../modules/core/经验.md)。这里只留本项目会反复用到的点。

1. 已经是官方 `module`。包入口是 `vector.art`，helper 在 `ops.art`。

2. `\name` 是 `this\name` 的简写。声明字段和调用兄弟时写成 `this\ops`、`this\vecScale` 更清楚。模块顶层不能写 `this\x: function`——那时还没有 `this`。

3. 外部函数用 `init` + `import.lean` 挂进来，不要在每个 method 里 `import`：

```arturo
init: method [][
    this\ops: import.lean ./{ops}!
]
```

4. `import.lean` 会隔离文件作用域。`ops.art` 里的函数不能再裸调兄弟名字，所以 helper 要自成一体。

5. 公开方法不要叫 `add` / `sub`。负数分量用 `@[neg 1 2]`。单位矢量用 `//`。
