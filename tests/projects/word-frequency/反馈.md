# word-frequency 反馈

## 已验证

- 动态字符串 key 的词频统计应使用 `get/set/key?`，不要使用 `dict\w`。
- `write.json result null` 可以直接生成 JSON 字符串，再用 `read.json` 做断言。
- 文本清洗阶段如果需要多次替换，应拆成多个明确语句，避免复杂右到左表达式难读。

## 可反馈给 skill 的点

- skill 可以增加一个“词频统计”完整 recipe，展示 strings + collections + JSON 的组合用法。
- 文档中应强调项目代码也要先查官方函数签名，而不是从 Python 直译 API 名。
