# 测试体系经验

1. `.art` 文件要短小、自包含，避免依赖网络。
2. 断言统一使用 `ensure.that:`，失败信息要能定位规则。
3. 成功输出统一：`PASS <module>/<case>`。
4. 文件类测试优先写 `/tmp`，避免污染仓库。
5. 运行器从 `skills/arturo-language/bin/arturo` 找 runtime，也支持 `ARTURO_BIN=...` 覆盖。
6. 每个 library 模块的**网页总章**（章节开头那篇）CLI `info` 没有。抽 skill 前要先打开 `https://arturo-lang.io/documentation/library/<module>`，用 runtime 跑总章示例，错的写进该分区 `反馈.md`。
